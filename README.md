# تصفية — جرد الأعمال وتصفية حساب الشركاء

تطبيق ويب يرافقك خطوة خطوة في الجرد السنوي وتصفية حسابات الشركاء، من الإعداد إلى الكشوفات الجاهزة للطباعة.

- **الواجهة:** GitHub Pages (HTML + JavaScript، دون مكتبات خارجية)
- **الحفظ:** Google Sheets عبر Apps Script
- **الحساب:** يتم في الواجهة فوراً أثناء الكتابة

## التركيب (مرة واحدة)

### 1) الخادم: Google Sheets + Apps Script
1. أنشئ Google Sheet جديداً فارغاً.
2. من القائمة **Extensions ← Apps Script**، الصق محتوى الملف [`apps-script/Code.gs`](apps-script/Code.gs) مكان الكود الموجود، ثم احفظ.
3. اختر الدالة `setup` من القائمة العلوية واضغط **Run**، ووافق على الصلاحيات.
   - تُنشأ الأوراق تلقائياً.
   - **المفتاح السري** يظهر في السجل (Execution log) وفي ورقة `Settings`.
4. **Deploy ← New deployment ← Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - انسخ **رابط Web app**.

> عند أي تعديل على `Code.gs`: Deploy ← Manage deployments ← ✏️ ← Version: New version، حتى يبقى الرابط نفسه.

> الشيت كله بالعربية: أسماء الأوراق (الشركات، الدورات، الشركاء، الأصول، الخصوم…)، رؤوس الأعمدة، والقيم (مؤكَّد، مشكوك فيه، سحب، إضافة…).
> إن كان عندك شيت قديم بأوراق إنجليزية، فإن `setup` يحوّله إلى العربية تلقائياً دون فقدان البيانات.

### 2) الواجهة
1. افتح التطبيق من GitHub Pages.
2. من ⚙️ **الإعدادات** ضع رابط Web app والمفتاح السري، ثم «اختبار الاتصال» فـ«حفظ».

قبل الربط يعمل التطبيق في **وضع تجربة محلي**، والبيانات تبقى في المتصفح فقط. ويمكن نقلها لاحقاً إلى Sheets بالتصدير والاستيراد (JSON) من الإعدادات.

## الخطوات داخل الدورة

| # | الخطوة | المرافق |
|---|---|---|
| 0 | الإعداد | تواريخ الدورة (السنة الكبيسة محسوبة)، نسب الجهد والاحتياط، الزكاة والنصاب (حاسبة 85غ)، الاقتطاعات |
| 1 | الشركاء | يتحقق أن مجموع نسب الجهد = 100% |
| 2 | حركة رؤوس الأموال | ترجيح كل سحب وإضافة بالأيام، وتنبيه للتواريخ خارج السنة وللسحب الزائد عن الرصيد |
| 3–6 | الاستثمارات، المخزون، الحقوق، الخزينة | حالة لكل بند: مؤكَّد / مشكوك (نسبة تخفيض) / معدوم…، ولصق قوائم من Excel |
| 7 | الخصوم | لصق قوائم من Excel |
| 8 | النتيجة والتوزيع والزكاة | تحقق مستقل من التوزيع، والخسارة على المال وحده |

| 9 | تحليل النتيجة والميزانية | من رقم الأعمال إلى النتيجة ومقارنتها بنتيجة الجرد، عتبة المردودية، 9 معدلات مالية مقارنة بالمقبول |
| 10 | الكشوفات والإقفال | 7 كشوفات للطباعة + الميزانية الافتتاحية + تصدير Excel (.xlsx) + إقفال الدورة |

**صفحة الشركة:** مقارنة تطور رأس المال والنتيجة والزكاة والمردودية عبر الدورات.

**الإقفال:** يجمّد النتائج في ورقة `Results` ويمنع التعديل، ويمكن فتحه عند الحاجة.

**الشركة النموذجية:** زر في الصفحة الرئيسية يحمّل شركة تعبئة براغي بثلاثة شركاء (2024 مقفلة، 2025 قيد الجرد).

**دورة جديدة:** تنقل رأس المال الجديد لكل شريك، وتجمع الاحتياط، وتنقل ديون الزكاة والاقتطاعات إلى الخصوم.

**قوائم التحقق:** تُعدَّل أسئلتها من ورقة «أسئلة المرافق» في الشيت (الأعمدة: المعرّف، الخطوة، السؤال، الترتيب).

## القواعد الشرعية المطبّقة
- الربح على المال يُوزَّع بحسب رأس المال **المستثمر المرجّح بالأيام**.
- **الخسارة** تُحمَّل على المال وحده بقدر الحصص، ولا اقتطاعات ولا احتياط ولا نصيب جهد عند الخسارة.
- **الزكاة:** وعاء كل شريك = نصيبه − حصته من الأموال غير الزكوية (الاستثمارات وتسبيق الكراء). النسبة 2.577% للسنة الشمسية أو 2.5% للهجرية.
- **الشريك المدين** يظهر رصيده سالباً، ولا يُخفى بصفر.
